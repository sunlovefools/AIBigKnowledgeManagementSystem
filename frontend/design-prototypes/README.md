# Light-Blue Premium Static Design Prototypes

These files are standalone visual prototypes. They do not import the current React app, do not call the backend, and do not change existing frontend routes or styling.

## How To Preview

Open any file directly in a browser:

- `aqua-command.html`
- `sky-glass.html`
- `blue-studio.html`

Each prototype includes internal tabs for:

- Login
- Collections
- Main workspace
- Profile
- Mobile preview

## Design Options

### Aqua Command

Recommended base.

Focuses on a crisp premium productivity workspace:

- Clear file, chat, and document hierarchy
- Strong selected and edit-mode states
- Obvious upload, ask, edit, and review flow
- Best balance between polished visuals and immediate usability

### Sky Glass

Most visually premium and optimistic.

Focuses on a softer, airier product feel:

- Translucent surfaces
- Larger spacing
- More welcoming login and collection screens
- Best if the product should feel modern, light, and visually impressive

### Blue Studio

Most professional and compact.

Focuses on dense repeated-use workflows:

- Stronger navigation
- Tighter panels and controls
- Document-editor-first workspace
- Best if the app should feel like a serious internal productivity tool

## Notes

- These prototypes use only HTML, CSS, and vanilla JavaScript.
- Static mock data is included only to represent the real product screens.
- After a design is approved, the selected direction can be translated into the existing React components and CSS.
