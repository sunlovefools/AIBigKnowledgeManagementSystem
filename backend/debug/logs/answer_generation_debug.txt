# CGI AI Big Knowledge Management System Project

## Project Overview
- **Project Title**: AI Big Knowledge Management  
- **Issued**: September 2025  
- **Expected Completion**: May 2026  
- **Company**: CGI  

## Project Purpose
The project addresses a fundamental limitation of Large Language Models (LLMs), which can only process a limited amount of text (tokens) at once. When fed excessive information, LLMs tend to "forget" earlier text and begin hallucinating. The solution involves:

- Storing documents in a specialized **vector database** (designed specifically for AI)
- Creating a server to connect AI tools with this database
- Enabling information retrieval from documents while maintaining context awareness

## Technical Components
The project focuses on integrating these key elements:
1. **Front-end user interface**
2. **Model Context Protocol (MCP) server**
3. **Vector database**
4. **AI techniques** including:
   - Retrieval Augmented Generation (RAG)
   - Cache Augmented Generation (CAG)
5. **LangChain framework**

## Practical Application
A primary use case involves loading thousands of documents from a knowledge base and enabling an LLM to provide business-specific answers based on these documents rather than its original training data. This represents a technical project at "the cutting edge of practical AI" that "can create tools that are genuinely useful today."

## Additional Information
- **Relevant Research Areas**: AI and Cloud
- **NDA Requirement**: Not required for students
