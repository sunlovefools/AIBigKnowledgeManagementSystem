## 1 Introduction

## 1.1 Overview

The software engineering group project module brings students together to work in team on a project. The module and project focus on the entire software development lifecycle, including the software specification (requirements analysis and design), development (implementation, coding, programming), validation and testing, documentation, and the management of the project. That is, this module is not ' just ' about writing code, but instead about the whole software engineering (SE) process.
