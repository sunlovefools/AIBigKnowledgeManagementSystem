```text
## Project Background Information

Modern AI tools are cool, but do you want to build something cooler?

All Large Language Models (LLMs) can only handle a limited amount of text at once, called tokens. If you feed them too much information, like multiple documents, they'll quickly 'forget' earlier text and start making things up (hallucinating).

One solution to this is to store your documents in a vector database (a database designed for AI), create a server to connect the AI tool with the database, and then use it to search and retrieve information from your documents whilst remembering previous answers and context.
```
